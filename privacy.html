Privacy / Datenschutz

MyFinance is a private, self-hosted application used by a single person for their own bank accounts. Account data is read only, stored only on the owner's own server and is not shared with anyone.

MyFinance ist eine private, selbst gehostete Anwendung, die ausschließlich vom Betreiber für die eigenen Konten genutzt wird. Kontodaten werden nur lesend abgerufen, ausschließlich auf dem eigenen Server gespeichert und nicht an Dritte weitergegeben.
